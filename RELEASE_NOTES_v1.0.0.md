# Goldengames PS5 Autoloader v1.0.0

Official release candidate promoted from the console-tested RC7 behavior.

## Highlights

- Auto Jailbreak remains on etaHEN 2.5B.
- Reopening Goldengames after a successful jailbreak does not automatically replay the jailbreak chain.
- Manual sender mode verifies elfldr on port 9021 before payload delivery.
- Manual payload menu includes etaHEN 2.5B, etaHEN 2.6B, Kstuff Lite 1.10, Payload Manager 0.5.1, WebSrv PS5 0.34, and ShadowMountPlus 1.7 alpha8.
- Compact Goldengames dashboard with the Goldengames JB icon and PS1-inspired installer presentation.
- Exact payload hashes are verified during the reproducible GitHub Actions build.
