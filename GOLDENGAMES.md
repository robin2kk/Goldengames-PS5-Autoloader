# Goldengames PS5 Autoloader

Custom fork of itsPLK's PS5 WebKit Autoloader.

## Planned v0.5 features

- Goldengames dashboard before exploit execution
- Auto Jailbreak mode
- etaHEN 2.5B launcher
- Kstuff Lite launcher
- Payload Manager entry
- UMTX2 path for firmware 1.00–5.50
- SlopKit path for firmware 9.00–12.00
- Dedicated Title ID: `GGAU00001`

## Upstream

This project is based on `itsPLK/ps5-webkit-autoloader` and preserves upstream attribution and GPL-3.0 licensing requirements.

The exploit and loader dependencies are pinned in `dependency-pins.json` for reproducible builds.
